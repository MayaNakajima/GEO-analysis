## 事前に用意するもの

- **Anaconda**（Anaconda Prompt が使えること）。バージョン確認：Anaconda Prompt で `python --version`。

## A. 初回だけ：config.json の確認

`GEO-analysis\config.json` を開き、3つのパスを自分の環境に合わせる（バックスラッシュは 2 個 `\\` で書く）。

```json
{
  "results_dir": "C:\\Users\\612316\\Downloads\\06_GEO\\monitoring\\data\\results",
  "reference_md": "C:\\Users\\612316\\Downloads\\06_GEO\\Set2_実績スクレイピング_reference.md",
  "output_html": "C:\\Users\\612316\\Documents\\GitHub\\GEO-analysis\\analysis.html"
}
```

- `results_dir`：monitoring の CSV 置き場（`results_*.csv` があるフォルダ）。
- `reference_md`：自社実績リファレンスの md ファイル。
- `output_html`：生成する HTML の出力先（既定のままで可）。

---

## B. 実行する（Anaconda Prompt）

1. スタートメニューから **「Anaconda Prompt」** を起動する。
2. アプリのフォルダへ移動する（`/d` はドライブが変わっても確実に移動するためのオプション）。

```bat
cd /d C:\Users\612316\Documents\GitHub\GEO-analysis
```

3. スクリプトを実行する（Anaconda では `python` を使う）。

```bat
python generate.py
```

成功すると次のように表示される：

```
[OK] C:\Users\612316\Documents\GitHub\GEO-analysis\analysis.html
     rows=552  hits=13  files=5
     competitors extracted (miss rows): 2392 mentions
```

> `python` で動かない場合は `py generate.py` を試す。

### パスを直接指定して実行する場合（config.json を書き換えたくないとき）

Anaconda Prompt に貼り付け（1 行で実行、パスはご自身の環境に合わせる）：

```bat
cd /d C:\Users\612316\Documents\GitHub\GEO-analysis
python generate.py --results-dir "C:\Users\612316\Downloads\06_GEO\monitoring\data\results" --reference "C:\Users\612316\Downloads\06_GEO\Set2_実績スクレイピング_reference.md" --out "C:\Users\612316\Documents\GitHub\GEO-analysis\analysis.html"
```

## C. 見る

生成された `analysis.html` を **ダブルクリックしてブラウザで開く**だけ。
上部タブで以下を切り替える：

1. **競合共起 (P1)**：当社が出なかった回答で挙がる競合ランキング。表の行クリックで根拠の回答へ。
2. **多軸クロス集計 (P1)**：行軸・列軸を選んで出現率クロス表。セルクリックで回答全文一覧。Set2 の崖を自動表示。
3. **引用URL (P2)**：ヒット回答の引用URL集計（非グラウンディングの現状は空）。
4. **自社突合 (P2)**：自社サイト掲載実績 × AI 言及有無。「掲載あるが未言及」＝強化余地。
5. **競合サイト (P3)**：将来実装（設計のみ）。

各タブの「この画面の見方」を開くと読み方の説明が出る。上部のフィルタ（期間／ドメイン／特異度／セット／モデル）で絞り込み可能。

## E. うまく動かないとき

| 症状 | 対処 |
|---|---|
| `results_*.csv が見つかりません` | `config.json` の `results_dir` が正しいか確認。フォルダ内に `results_` で始まる CSV があるか確認。 |
| `python は見つかりません` 等 | Anaconda Prompt から実行しているか確認（通常のコマンドプロンプトでは PATH が通っていない場合あり）。それでもだめなら `py generate.py` を試す。 |
| フォルダに移動できない | `cd /d C:\Users\...\GEO-analysis` のように `/d` を付ける。 |
| 文字化けする | CSV は UTF-8 BOM 前提。monitoring が出力したものをそのまま使う。 |
| HTML を開いてもグラフが出ない | 社内ネットで CDN（cdn.jsdelivr.net）がブロックされていないか確認。表・数値はネット無しでも表示される。 |
| 競合候補にノイズ（非企業）が混じる | 仕様上、候補は目視確認前提。除外は `generate.py` の `GENERIC_STOP` に語を追加して再生成。 |
